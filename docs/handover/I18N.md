# Arabic interface

_Confidential. Property of Tiger Capital AI. Prepared for Tiger Capital AI and the reviewer of the Arabic wording._

## What it is

A language switch (English, العربية) in the top bar. Choosing Arabic sets the page language and right-to-left layout together; the choice is remembered in the browser. Numbers keep Western digits (0–9) and the stored units in both languages, so a figure reads exactly as it is stored and as it appears in an export. Dates use Arabic month names. Charts keep the conventional left-to-right time axis.

Every screen lays out right to left, fits a phone, and passes the structural accessibility checks in Arabic (browser suite, `e2e/arabic.spec.ts`).

## What stays English, on purpose

- **Sentences composed from the stored records** (signal titles and details, briefing headline, caveats, readiness item text, the Assistant's drafts and the facts it was given). They are written by fixed code on the server in English. They are shown inside Arabic pages as English text with their own direction. Translating them means composing them from structured values in each language, which is a separate piece of work and must not alter a figure.
- Server error messages, audit and evidence content, document text, source and series names, identifiers.
- The handover documents and the exports.

## Reviewing the wording

The Arabic was written by the build team's assistant and **has not been reviewed by a native Arabic speaker**. It must be reviewed before it is shown to a client. Wording lives in one file, `apps/web/src/i18n-ar.ts`, as English text mapped to Arabic. To review: read the file, change any wording, then run:

```bash
node scripts/i18n.mjs
```

It lists any message with no Arabic. The unit test `tests/web/i18n.test.ts` fails if a message has no Arabic, a placeholder (for example `{n}`) is missing or renamed, an entry is unused, or a number is written in Arabic-Indic digits.

## Adding or changing a screen

Wrap each visible string with `t("English text")`; use `tx("English text")` where the string sits in a constant and is resolved at render with `t(...)`. Placeholders use `{name}`. Add the Arabic in `i18n-ar.ts`. Text that comes from the server and is shown as it is goes inside `<Data>` (`lang="en" dir="auto"`). Avoid plural templates: Arabic plurals need more forms than English.
