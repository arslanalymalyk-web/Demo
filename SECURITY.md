# Security

TIGERIS AI OS is confidential software of Tiger Capital AI, deployed on each client's own infrastructure.

## Reporting a vulnerability

Report it privately to Tiger Capital AI's security contact. **The named contact and address are to be filled in before the first client deployment** (see `docs/handover/OPEN-ITEMS.md`). Do not open a public issue, and do not test against a client's live deployment without written permission.

Include what you found, how to reproduce it, and what you think it affects. Do not include real client data.

## What the build already does

See `docs/handover/SECURITY.md` for the threat model and control inventory, `docs/handover/CONTROL-MATRIX.md` for the mapping to SOC 2 and ISO 27001, and `docs/handover/VERIFICATION-REPORT.md` for what was proved and what was not.
